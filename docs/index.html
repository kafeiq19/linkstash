    产品能力

    Capabilities
    1. 01

      保存

      粘贴 URL 入库。服务端异步抓取 Open Graph / 标题 / 站点图标；抓取失败不影响保存，队列先建立。

    2. 02

      队列

      未读、已读、归档、收藏四种状态。收件箱默认只含未读与已读，归档单独存放，避免列表被旧链接淹没。

    3. 03

      检索

      按标题、摘要、URL 关键词搜索，按标签名筛选。标签同用户唯一，删除标签仅解除关联，不误删书签。

    4. 04

      账号

      注册 / 登录，JWT（HS256）鉴权。书签与标签按 user_id 隔离，越权访问一律按不存在处理。

    技术规格

    Runtime
