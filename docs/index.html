Linkstash 是一个前后端分离的稍后读/书签站。这个页面是静态落地页 + 浏览器本地演示； 完整版（Vue 3 + Spring Boot + SQLite）在仓库里自行部署。

试试本地演示 本地跑完整版
Vue 3 Spring Boot 3 MyBatis-Plus SQLite JWT 多用户

完整版能做什么

下侧演示覆盖保存 / 筛选 / 收藏；完整版还有账号隔离、标签管理与元数据抓取。

⌘

一键保存

粘贴 URL 即可入库；服务端异步抓取标题、摘要与站点图标。

☰

阅读队列

未读 / 已读 / 归档 / 收藏，配合标签与关键词搜索，很快找回。

◎

多用户隔离

注册登录，数据按用户隔离；JWT 鉴权，适合内网自托管。

浏览器本地演示

数据只存在这台设备的 localStorage 里，刷新还在。可当书签草稿本用。

说明：GitHub Pages 只能托管静态资源，完整 API（Java + SQLite）需要你自己的服务器或内网机器。 仓库内 backend/ 与 frontend/ 可按 README 启动。
